My Dev Projects

Here are some of my projects that I have done :)

NF online shop

NF Online Shop is a full-stack e-commerce platform built with HTML, CSS, JavaScript, and Node.js on the backend. I used Firebase for user authentication and data storage and Amazon Web Services (AWS) for managing product images. The live is not available due to Chrome security restrictions, but you can check the repository on GitHub.

English Courses Website

This project is a simple one-page website for selling English courses for Ukrainians. The site was built using HTML, CSS, and JavaScript. It includes a price calculator and a form for users who want to collaborate in the future. It is quite similiar to the Flower and Pizza Store in its functionality, however different design structure was applied.

Interpol/Crime Control App

This project is a system for tracking criminals, their organisations, and the crimes they committed. Users can browse criminal cases and see details like opening and closing dates, and admins can add new criminals and crimes, edit records, open or close cases, and set prison terms. This system was built in C#, Windows Forms and SQL Server was used as a database.

Flower Store

This project is a simple one-page website for selling flowers. I focused a lot on the visual design to make it look appealing. The site was built using HTML, CSS, and JavaScript. It includes a price calculator and a form for users who want to collaborate in the future. I used Anime.js to animate the buttons and applied event delegation for switching images in the “Our Service” section. There's also a responsive burger menu for the mobile version.
